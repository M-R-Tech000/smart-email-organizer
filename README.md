# AI-Powered Smart Email Organizer & Digest

An automated Python script designed for Virtual Assistants and Executive Assistants to save hours of manual email sorting. It automatically connects to an inbox, filters unread emails, classifies them into smart categories, and generates an AI-powered summary for each email, exporting a clean daily report into a CSV/Excel file.

## 🚀 Features
* *Automated Email Fetching:* Connects securely to Gmail/Outlook using IMAP.
* *Smart Classification:* Automatically categorizes emails into Financial, Calendar & Meetings, Customer Support, or General.
* *Local AI Summarization:* Uses Hugging Face's BART model to summarize long emails locally without paying for external APIs.
* *Daily Executive Digest:* Generates a structured daily_email_digest.csv report ready to be sent to executives.

## 🛠️ Tech Stack
* *Language:* Python 3.x
* *AI/NLP:* Transformers (Hugging Face), PyTorch
* *Data Automation:* Pandas
* *Security:* Python-dotenv (Credentials protection)
